# LUMEN · 光与暗的视觉档案

独立 HTML、CSS、JavaScript 网站，无需安装依赖或编译。8 张用户提供的图片均保存在 dist/assets 中。

## 使用

直接用浏览器打开 dist/index.html，即可浏览全部作品。也可在当前目录执行 `node server.cjs`，然后访问 http://localhost:4318。

## 交互

- 首屏切换全部 8 幅作品；点击进入详情。
- 按暗色、亮色或收藏筛选；切换画廊密度。
- 收藏保存在当前浏览器的本地存储中。
- 原图详情、尺寸、配色与构图解读；沉浸模式。
- 键盘左右箭头和触屏滑动切图，Esc 关闭。
- 三组视觉解读 tabs，支持键盘左右切换。

中文标题是展览索引名，非作品官方名称。文案仅依据图片可见内容；原始图中文字保留。未添加音频或虚构作者信息。

字体在线加载 Noto Sans SC / Noto Serif SC；离线时自动使用系统字体。所有功能和图片均可离线使用。
